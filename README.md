# Haftalık Antrenman Programı

Tek dosyalık kişisel antrenman sayfası: salon programı, koşu/yüzme takibi, beslenme listesi ve gelişim grafikleri.
Kayıtlar yalnızca sayfayı açan tarayıcıda (`localStorage`) tutulur; burada saklanmaz, kimseye gitmez.

Bu, çalışma kopyasının yayın sürümüdür: anatomi figürleri (bir kas uygulamasının ekran görüntüleri, telifi onlara ait)
bu kopyaya dahil edilmedi, sayfa onlarsız da tam çalışır.
